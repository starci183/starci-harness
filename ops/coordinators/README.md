# Coordinator briefs

The CLI renders [supervisor.md](supervisor.md) for the host's owner channel and [kernel.md](kernel.md) for each Orca
workflow. The rendered copies live under `.runtime/`; launch prompts name those files instead of carrying the
brief in argv. Read the whole rendered brief before acting. The role boundary is owned by
[roles.md](../../contexts/harness/roles.md); coordinator routing tiers live in [routing.yaml](../routing.yaml).
