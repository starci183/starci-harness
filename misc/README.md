# Misc

Know-how for work that is not code and not the harness itself: filming, cutting and voicing a product demo, and the like.
It sits beside `contexts/` (which holds the harness rules and how app code is written) and is read on demand: AGENTS.md
"Misc work" names which file to read for which job. Each file owns its topic; a product's own script or copy stays in its
`.starciwork` or its own folder.

| job | read |
|---|---|
| film a product demo: record the real app by code, mock "before" scenes, automatic zoom, voice last, and the tech stack (Playwright + Chrome, ffmpeg, Remotion, AI voice) | [film.md](film.md) |
