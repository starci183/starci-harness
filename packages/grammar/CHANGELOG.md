# Changelog

Versioned history starts at beta; earlier history is in git.

## 0.61.1 - 2026-11-26

- Fixed (h-offset-pop-seams): every Offset Pop row seam is one 2px ink line, not only a ListRow's. Common gains the token `--grammar-seam-width` (default the hairline, so Core is unchanged); the Offset Pop root binds it to `--offset-pop-outline-width`, and the seams of a disclosure item, note, schema and kv row, schedule and Markdown table row, DataTable row, header line and mobile list row, description pair, upload row, interval row and media list row read it. The family's own `[data-grammar-row]` seam rule is gone: the token carries it. `offsetPopRuleConformance` BOUNDARY-3 and BOUNDARY-5 state the rule. No API change.

## 0.61.0 - 2026-11-26

- Changed (h-grammar-chat-avatars, NIVO feedback 2): a figure that is a link (`Section kind="figures"`) draws no chevron or arrow; the whole cell is the press target, shown by the pointer cursor and the row hover surface. `DNA-COMMON-FIGURE-LINK-CUE` now says so (it measures zero cue glyphs); `data-grammar-figure-cue` and `.starci-core-figure-cue` are gone.
- Added (feedback 3): `MessageFrame`, the one chat card for a structured message frame: the title, a status dot only for a real state, field and value rows, at most three actions (the first is the card's primary), a muted meta line, in the compact density (`MessageCard` gains `status` and `density="compact"`). A kind the app does not know, or a card with no title, falls back to its text line (`data-grammar-frame="card" | "text"`, `data-grammar-frame-kind`). `MessageBubble format="markdown"` and `MessageMarkdown` draw a message as safe Markdown (bold, italic, strikethrough, inline code, links, lists; no raw HTML, heading, image, table or fence, an unsafe link is its words). Laws `DNA-COMMON-FRAME-CARD-ONE-PRIMARY` and `DNA-COMMON-FRAME-CARD-MAX-ACTIONS`.
- Added (feedback 4): `ChatFrame empty`, what an empty thread shows, centred in the message area on both axes (`DNA-COMMON-CHAT-EMPTY-CENTRED`); a bare empty notice as the thread's only child is centred the same way.
- Fixed (feedback 5): a circle `Avatar` is a square box (aspect ratio 1, never squeezed by a flex row or stretched by a slot) clipped by a 50% radius at every size (`DNA-COMMON-AVATAR-ROUND`).
- Changed (feedback 6): `AvatarGroup layout="grid"` is no longer one big circle cut into tiles. It is the Zalo-style cluster: small round member avatars set close in a 2 by 2 inside an Avatar-sized square that is never clipped (two members on the diagonal, three as two over one, four or more as three and a count cell that reads the number of members of the whole group, not the hidden ones). `photo` replaces the cluster with the group's own picture. The grid ignores `max`; `avatarClusterCells` is the new shape rule (`avatarGroupTiles` stays for callers). `DNA-COMMON-AVATAR-CLUSTER`.
- Added (feedback 7): `Avatar channel` (and `channelLabel`): a small round channel badge in the avatar's bottom end corner, outside its clip, with the simple-icons logos of `CHANNEL_LOGOS` (Messenger, Instagram, Facebook, Zalo, WhatsApp, Telegram, TikTok, Gmail, LINE, Viber, WeChat, X, YouTube, Discord, Google Chat) and Grammar's own `email` envelope; brand colours are `--grammar-channel-*` tokens. `DNA-COMMON-AVATAR-CHANNEL-BADGE`.
- Manual steps: an app that read `data-grammar-figure-cue` or relied on the 4-tile `AvatarGroup layout="grid"` with a `+N` cell reads the headcount in the count cell now (4 members: three and "4").

## 0.60.3 - 2026-11-26

- Fixed (h-grammar-strip-fade-tabs, StarCi Next audit round 5): a strip that scrolls only sideways fades its end again. Breadcrumbs, the `DataTable` scroller, the fenced code `pre`, the markdown table frame and the top bar's navigation took their fade from `animation-timeline: scroll(self)`, the BLOCK axis, which they never scroll, so the timeline stayed inactive and `--grammar-fade-end` stayed 0px (a long last crumb was cut mid-word at 390px). They follow `scroll(self inline)`; a browser without scroll-driven animations still skips the fade.
- Fixed (h-grammar-strip-fade-tabs, StarCi Next audit round 6): the selected tab of a scrolling strip opens clear of the strip's fading edge, not only of the page control. The reveal brought the tab to the scroller's bare edge, where the vendor `ScrollShadow` masks its last `--scroll-shadow-size` (64px) on a side where more tabs wait, so the label dissolved beside the next control ("Khi có sự cố" at 390px). It now keeps that fade's width clear on each side (a tab wider than the room is centred) and reveals again once the web fonts are in. Spec `specs/sideways-strips.browser.spec.mts`, story `Navigation & Data/Tabs overflow/Phone Header Selected Middle`.

## 0.60.1 - 2026-11-26

- Fixed (h-offset-pop-parity): Offset Pop covers the renderers that landed after its last pass. The family root sets four Common tokens: `--grammar-border-edge` (the 2px ink outline: code block, GradedChoice answer and key, the other party's message), `--grammar-shadow-popover` and `--grammar-shadow-lift` (the hard offset: a popover, which had kept Common's soft `!important` shadow, the reaction picker, a lifted Board card, the pane trigger) and `--starci-core-surface-radius` (Board columns and cards and a framed EmptyNotice take the family card radius instead of Common's 32px; the `--starci-core-card-radius` hook still wins). The new `components-content.css` adds outlined, offset Board cards with press travel, a dashed origin slot and 2px drop slot and end band, the ink ring on the Progress, ProportionBar, SegmentBar and FunnelChart tracks, pressable GradedChoice answers, outlined SchemaForm marks, proposals and ConflictCard sides, and the pink offset of a `SurfaceCard emphasis="accent"`, which the family's card rule had hidden. A SchemaForm field left empty keeps its warning edge and a field being written keeps its paint, which the family's field box had covered. No API change.
- Fixed: `offsetPopRuleConformance` claims only what the CSS does. It drops MARGIN-2, OVERFLOW-2, PADDING-3 and PADDING-4 and the DataTable, Calendar and Timeline mentions, which had no rule behind them. FONT-6 now says the display weight resolves to 500.
- Added: story `Offset Pop/Parity` shows the learning screens (lesson list, practice step, streak and progress, profile, leaderboard) and the content renderers, at 1440 and 390, light and dark, with the family palette. The playbook (`@starci/hfs` knowledge, `grammars/offset-pop/playbook.yaml`) is rewritten against the current API and adds the `lesson-list`, `streak-progress`, `profile` and `leaderboard` shapes.

## 0.60.0 - 2026-11-26
- Breaking (h-grammar-board-forms): `BoardColumn.canDrop` answers `boardAllow`, `boardRefuse(reason)` or `boardNeedsData(kind)` (was `null` or a reason string). Manual step: wrap each `canDrop` result: `null` becomes `boardAllow`, a string `reason` becomes `boardRefuse(reason)`. `needsData` takes the drop but leaves the card where it was and calls the new `Board onNeedsData(move, kind)` so the app can open a dialog (a booking time, a reason a lead was lost) and move the card itself; `moveLabels.announceAsk` is what a screen reader hears.
- Added: board drag and drop is drawn. A card shows its grip (six dots, new `TablerGripVertical`) on hover and focus; while dragged it leaves an origin slot (a dashed, emptied card) and travels as a lifted card (the popover shadow); the stage under it opens a drop slot with `BoardColumn.dropHint` (`title`, `detail`); `Board endBand` is a wide drop place after the last stage that exists only while dragging; Alt and an arrow reach it by keyboard. `RowDrag.isOrigin` is the row's flag. Story `Surfaces/Board drag and drop`.
- Added: `FunnelChart layout="steps"` (the compact funnel of one row: a column per stage with its count and the share that came through, side by side from 36rem of chart width), `lost` (the side bucket: `label`, `count`, `note`) and `quiet`.
- Added: `BarChart highlight` (chosen bars by x values or a test), `highlightTone`, `capacity` (a labelled dashed line, the scale always reaches it), `showValues` and `quiet`; `barMarkFills`, `CHART_QUIET_INK` and `CHART_QUIET_MUTED`. New `SegmentBar` (rows of bars on one scale, each split into the series' segments, with `quiet`). The quiet colour mode keeps a screen to the 10% accent budget.
- Added: `SchemaForm` (a form drawn from the JSON Schema a zod schema emits: lines, several lines, numbers, switches, choices, image and file upload slot, lists of lines, rows to add, remove and reorder, a `meters` reading such as 15 / 15 seconds; the markers "edited by you" and "being written", the agent's proposal as a difference with Accept and Reject, a required field left empty, `schemaFormMissing`), `ApprovalCard` (the card of facts with a quick edit of chosen fields), `WorkbenchSlot` (the first tab of an agent with its empty state), `NoteList` and `NoteRow` (what an agent remembers), `ConflictCard` (two notes that disagree). Story `Forms/Schema form and agent surfaces`.
- Fixed: the `FunnelChart` separator before a count is its own span (`starci-core-funnel-sep`) so the steps layout can leave it out.

## 0.59.3 - 2026-11-25

- Fixed (h-grammar-mermaid-fit, the Next UI audit round 3): `MermaidDiagram` opens the WHOLE drawing at its first view, contain-fitted (zoom = min(1, room width / width, room height / height)) and centred in the room the 64px controls row leaves clear, so no node is cut on any side and the zoom buttons never stand over one (a tall lesson diagram cut "Loyalty" in half under the controls at 390px; a wide one ran off both edges at 1440 and 390).
